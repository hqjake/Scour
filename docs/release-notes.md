Command palette (Ctrl+K), reinstall kit and automatic updates.

**New in this version**

- **Command palette** — press Ctrl+K and type to open any page, run an action or uninstall a program.
- **Reinstall kit** — save your apps to a file and reinstall them all on a new PC with winget.
- **Automatic updates** — Scour now checks for new releases and updates itself (Settings → About to turn it off).
- **Bloatware remover** and **Privacy tweaks** pages.
- Repair center, App updates, PC health score, scheduled cleaning and tray icon.

Download `Scour.exe` below — a single file, no installation or .NET runtime needed. Windows will ask for administrator rights.
