Network toolkit, driver cleanup, context menu and extension managers, and "what changed" on disk.

**New in 1.2.0**

- **Network** — switch DNS (Cloudflare, Google, Quad9, AdGuard…) with live latency for each, run a speed test, see saved Wi-Fi passwords and edit the hosts file.
- **Drivers** — remove old driver versions Windows keeps after updates, and back up / restore all drivers before a reset.
- **Context menu** — switch off right-click menu clutter that programs added; every switch can be turned back on.
- **Browser extensions** — every extension in every browser with what it can do in plain words, plus removal of extensions forced in through the registry.
- **Disk analyzer** remembers each scan; the new *What changed* tab shows which folders grew since last time.
- Command palette learns the new pages and actions (speed test, Wi-Fi passwords, driver backup).

Download `Scour.exe` below — a single file, no installation or .NET runtime needed. Installed copies of Scour 1.1 offer this update automatically.
